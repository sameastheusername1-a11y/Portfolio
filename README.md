# Student Hackathon Portfolio

A simple, responsive, one-page student portfolio made with plain HTML and CSS.

## Personalise it first
Open `index.html` and replace:
- `Your Name` / `yourname` / `YN`
- `YOUR-GITHUB-USERNAME`
- `YOUR-EMAIL@example.com`
- Skills and project descriptions with details you can confidently explain

Remove any skill or project description that does not accurately represent your experience.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `portfolio`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will usually look like:
   `https://YOUR-GITHUB-USERNAME.github.io/portfolio/`

No frameworks, build tools, or dependencies are required.
